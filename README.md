# AKKOYUNLU Fiyat Teklifi

Sondaj ve pompa fiyat teklifi hazirlama programi.
Tek dosyadir; gorseller ve PDF motoru dosyanin icine gomuludur, internet baglantisi gerektirmez.

- **Sondaj Fiyat Teklifi** — bolumler, kalemler, genel hususlar, referanslar
- **Pompa Fiyat Teklifi** — dalgic pompa, motor, pano, kablo, kolon borusu, montaj
- Otomatik teklif no ve tarih (tarihler elle de degistirilebilir)
- Kayitlar programin kendi sistem arsivinde tutulur
- A4 PDF cikti
- Telefon, tablet ve bilgisayarda calisir

Yayin adresi: https://onixsondaj.github.io/fiyat-teklifi/
